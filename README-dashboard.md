## 数据源与接口

同花顺金融数据 API（`https://fuyao.aicubes.cn`），请求头 `X-api-key`，已验证支持跨域（CORS）。
每只标的每次刷新调用 3 个接口，共 72 次请求，全局并发上限 6，遇 `code=4001`（QPS 超限）自动退避重试。

| 表格字段 | 来源接口 | 字段 |
|---|---|---|
| 价格 / 涨跌幅 / 最高 / 最低 | `GET /api/fund/market/snapshot` | `last_price` `price_change_ratio_pct` `high_price` `low_price` |
| 净值 / 规模 / 基金公司 | `GET /api/fund/profile/detail` (`fund_type=exchange`) | `unit_nav` `fund_scale` `mgmt_name` |
| 年涨跌幅 | `GET /api/fund/performance/returns` | `return_nowyear`（今年以来）、`return_year`（近1年，悬停可见） |
| 溢价率 | 本地计算 | `场内价 ÷ unit_nav − 1` |

**溢价率是估算值。** 该 API 不提供盘中 IOPV，QDII 净值按 T‑1/T‑2 披露且不含当日美股涨跌，因此该列与交易所实时 IOPV 溢价存在系统性偏差，仅适合同类标的之间横向比较，不能直接当作套利依据。

`跟踪指数` 一列取自 `ETF_LIST.md` 的静态标注（API 未提供该字段）。

## 功能

- 12 列固定列序；价格、涨跌幅、溢价率、规模、最高价、最低价、年涨跌幅可排序（点击列头：降序 → 升序 → 恢复默认代码升序），排序偏好写入 localStorage
- 手动「刷新」按钮全量更新，加载中显示进度条 + 逐行骨架屏，完成后展示行情时间与成功/失败统计
- API 密钥：设置面板内验证（调用一次行情接口）→ 成功后存入 localStorage → 可显示/隐藏/清除
- 错误分级提示：密钥无效、网络失败、部分标的失败、部分字段缺失，各自给出对应的重试或跳转设置操作
- **买点分级（可选）**：部署配套的分级服务（Docker）后新增「分级」列，对当前溢价 > 2% 的标的给出 A/B/C/D 等级，点「详情」进入同页详情视图（双维度分位趋势图 + 分级占比 + 60 日逐日明细）。详见 [DEPLOY-buypoint.md](DEPLOY-buypoint.md)
- 列头 ⓘ 与数值单元格带说明气泡：悬停即显（无延迟）、点击/触屏点按可锁定、Esc 或点击别处关闭；点 ⓘ 不会误触发该列排序
- 浅色/深色主题（默认跟随系统，可手动切换）；移动端横向滚动 + 代码列吸附


然后访问 http://127.0.0.1:8123/etf-dashboard.html （直接双击文件用 `file://` 打开也可以，接口跨域已放开）。

## 部署到 Cloudflare Pages

把 `etf-dashboard.html` 放进 Git 仓库，Cloudflare Pages 新建项目指向该仓库：

- Framework preset：`None`
- Build command：留空
- Build output directory：仓库根目录（或 `etf-dashboard.html` 所在目录）

密钥不打包进页面，由每位访问者在自己浏览器里各自填写并保存在本地 localStorage。

## 买点分级

基于 `qdii-etf-dual-percentile-buypoint` 技能的双维度分位框架：把**底层指数分位**与**场内溢价分位**
放进同一个 60 交易日窗口，两个维度是否同时落在下四分位，交叉出四档：

| 档 | 含义 |
|---|---|
| **A** | 指数低 + 溢价低 —— 两维度同时低 |
| **B** | 指数不低 + 溢价低 —— 溢价理想、指数位置一般 |
| **C** | 指数低 + 溢价不低 —— 价格新低多半是指数跌出来的，便宜被溢价吃掉了 |
| **D** | 两维度都不低 |

核心是这两个维度**往往负相关**：底层指数跌得越快，套利/申赎机制越来不及压平溢价，场内资金
反而把溢价顶得更高。所以只看 ETF 场内价创新低就追入，很可能买的是被高溢价抵消掉的"假便宜"。

所有阈值都取自当前窗口的真实分布，不是拍脑袋定的固定数字 —— 固定数字往往在真实样本里一次都
没出现过，会让标准要么永远触发不了、要么形同虚设。**窗口滚动后阈值会漂移，不能当永久基准。**

该功能需要后端支撑（浏览器拿不到海外指数数据，Yahoo 不返回 CORS 头）。后端是一个零依赖的
Node 容器，同时把本看板一并托管 —— 同源部署下不需要任何配置。部署见
[DEPLOY-buypoint.md](DEPLOY-buypoint.md)。不部署不影响看板其余功能。
